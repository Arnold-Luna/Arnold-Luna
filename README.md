## Highlighted Projects

### SOC, SIEM, And Incident Response

- **[Enterprise SIEM Lab - Wazuh + Suricata + Kali Linux + Fail2Ban](https://github.com/Arnold-Luna/cybersecurity-projects/tree/main/Enterprise%20SIEM%20Lab%20%E2%80%93%20Wazuh%20%2B%20Suricata%20%2B%20Kali%20Linux%20%2B%20Fail2Ban)**
  Simulated reconnaissance and SSH brute-force activity, detected events in Wazuh/Suricata, mapped the behavior to MITRE ATT&CK, and validated automated containment with Fail2Ban.

- **[RIG Exploit Kit Malware Investigation](https://github.com/Arnold-Luna/cybersecurity-projects/tree/main/security-onion-rig-exploit-kit-investigation)**
  Reconstructed a malware infection chain using Security Onion, Kibana, Sguil, CapME, Wireshark, NetworkMiner, and VirusTotal hash analysis.

- **[Windows Host Remcos RAT Investigation](https://github.com/Arnold-Luna/cybersecurity-projects/tree/main/windows-host-remcos-rat-investigation)**
  Investigated a Windows host compromise, identified downloaded executables, tied activity to Remcos RAT, and documented containment recommendations.

- **[HTTP SQL Injection And DNS Exfiltration Analysis](https://github.com/Arnold-Luna/cybersecurity-projects/tree/main/http-dns-exfiltration-analysis)**
  Analyzed SQL injection evidence and suspicious DNS queries carrying encoded data through allowed DNS traffic.

### Cloud Security

- **[AWS IAM Threat Detection & Automated Alerting Pipeline](https://github.com/Arnold-Luna/cybersecurity-projects/tree/main/cloud-projects/AWS%20IAM%20Threat%20Detection)**
  Built an AWS-native detection workflow using CloudTrail, EventBridge, Lambda, DynamoDB, SNS, and CloudWatch to identify high-risk IAM activity.

- **[AWS KMS CloudTrail S3 Encryption Lab](https://github.com/Arnold-Luna/cybersecurity-projects/tree/main/cloud-projects/AWS%20KMS%20CloudTrail%20S3%20Encryption%20Lab)**
  Configured S3 encryption with a customer-managed KMS key, validated access behavior, and documented CloudTrail evidence for KMS and S3 activity.

### Security Engineering And Defense

- **[AI-Assisted Web App Pentest - CAI Framework](https://github.com/Arnold-Luna/cybersecurity-projects/tree/main/AI-Assisted%20Web%20App%20Pentest%20-%20CAI%20Framework)**
  Documented an authorized AI-assisted web application security assessment with scoped testing, endpoint review, and sanitized evidence.

- **[Windows 11 DISA STIG Remediation Lab](https://github.com/Arnold-Luna/cybersecurity-projects/tree/main/Windows%2011%20DISA%20STIG%20Remediation%20Lab)**
  Remediated a DISA STIG finding using PowerShell and Windows registry hardening, then validated the improvement with post-remediation evidence.

- **[Extracting An Executable From A PCAP](https://github.com/Arnold-Luna/cybersecurity-projects/tree/main/pcap-executable-extraction)**
  Practiced packet-level file recovery by extracting a Windows executable from HTTP traffic and identifying safe malware-analysis next steps.
